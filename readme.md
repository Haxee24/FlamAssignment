# Real-Time Edge Detection Viewer (Android + OpenCV + OpenGL + Web)

This project is a minimal skeleton for the Real-Time Edge Detection Viewer.

It contains:
- Android project folder (`app/`)
- Native C++ folder (`jni/`)
- OpenGL rendering folder (`gl/`)
- TypeScript web viewer folder (`web/`)

Further commits will add:
- Camera integration
- JNI + OpenCV native pipeline
- OpenGL ES rendering
- TypeScript web UI

This is commit 1: base skeleton.
